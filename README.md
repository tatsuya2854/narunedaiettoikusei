# なるねぇといっしょ｜笑けるダイエット育成

なるねぇを「たまごっち」みたいに育てる、1ファイル完結（`index.html`）のスマホ向け育成アプリ。
ビルド不要。`index.html` を開けば動く。データは端末の localStorage に保存。

## 育成の仕組み

| 要素 | 内容 |
|---|---|
| **たまご → 進化** | 初回はたまご。タップで温めて孵化。お世話した日数で `ちび → なるねぇ → おとな → カリスマ` と大きくなる（2日 / 5日 / 10日） |
| **ぷに（体型）** | 食事で増え、運動・ダンス・片付けで減る。数値に応じて横に太ったり、細く背が伸びたりする |
| **きれい** | 部屋の片付け・ダンス・ヘルシー食で上がる。高いとキラキラのオーラ、低いとくすんでモワモワ線が出る |
| **部屋の散らかり** | うんちの代わり。時間経過（約2.5時間に1つ）とごほうび食で床にゴミが落ちる。タップで片付け。放置すると部屋がくすみ、キゲンときれいが下がる |
| **ダンス** | リズムゲーム（約20秒）。♪が◯に重なった瞬間にタップ。ランク S/A/B/C で ぷに・きれい・キゲンが変わる |
| **クローゼット** | 実績で服8種・アクセ7種が増える。服はスプライトのシャツ／短パンの画素だけ Canvas で色替え（絵を描き足さずに衣装が変わる） |

## 実績で手に入るもの

- 服：ミントジャージ（運動5回）／ピンクワンピ（きれい80）／ネイビースポ（ダンスA）／ラベンダー（7日連続）／くろスポ（片付け20回）／あかスポ（スタンプ30）／ゴールド（カリスマ進化）
- アクセ：リボン（初めてのお世話）／おはな（片付け10回）／ハチマキ（運動10回）／サングラス（ダンス5回）／ヘッドホン（ダンス10回）／クラウン（ダンスS）

## 3Dモード

右上の吹き出しの下にある `3D / 2D` ボタンで切り替わる（初回は3D）。WebGLが使えない端末では自動的に2Dのまま、ボタンも出ない。

- **キャラは手組みの3Dモデル**。頭・胴・腕・脚・ポンポン・耳・ポニーテールをプリミティブで組み、トゥーンシェーディング＋反転ハルの黒フチで、元の絵のフラットな塗りと太い輪郭線に寄せている。
- **顔はCanvasに描いて球に巻く**。表情（にっこり／ウインク／寝顔／しょんぼり）をその場で描き替えるので、2Dの12ポーズに縛られない。
- **モーションは手付け**。idle / dance / jump / cheer / clap / run / kiss / tilt / shy / sleep / win / sad を、時間から各パーツの角度を計算して作っている。外部のモーションデータは使っていない。
- **ゲームの状態がそのまま見た目になる**：ぷに＝胴の横幅、成長段階＝全体の大きさ、きれい＝ツヤとライト、服＝マテリアルの色、アクセ＝頭に付く3Dの小物。
- **部屋も3D**。ドラッグでぐるっと見回せる。クローゼットとChenMeの瓶はレイキャストで直接タップできる。散らかりものは2Dのまま床の上に重ねている。

three.js（r149・MIT）をファイルに同梱しているので、外部への通信は無し。そのぶん `index.html` は約1MB（gzipで約440KB）になっている。

## 開発メモ

- デバッグ用 API：`window.__naru`（`set({...})` / `mess(n)` / `evolve()` / `dance()` / `unlockAll()` / `set3D(true)` / `g3()` など）
- 3Dの実装は `Naru3D`（`create(canvas)` → `apply` / `outfit` / `accessory` / `play` / `look` / `pick` / `update`）に閉じてある
- 旧バージョン（v1）のセーブは自動で引き継ぐ（体重・連続日数・スタンプを保持し、遊んだ日数ぶん育った状態で始まる）
