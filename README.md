# なるねぇといっしょ｜笑けるダイエット育成

なるねぇを「たまごっち」みたいに育てる、スマホ向けの育成アプリ。
データは端末の localStorage に保存。

## 置くもの

| ファイル | 中身 | 大きさ |
|---|---|---|
| `index.html` | HTML・CSS・ゲームのコード全部（メッシュのデータ込み） | 143KB（gzipで52KB） |
| `naru.webp` | なるねぇのテクスチャ（体・頭・ポニテ・顔のパーツ） | 91KB |
| `jar.webp` | 棚のChenMeのボトル | 7KB |
| `icon.png` | ホーム画面用のアイコン | 40KB |

**4つとも同じ場所に置く**（サブディレクトリは不可）。静的ファイルを置けるところなら何でも動く。

画像を埋め込まずに別ファイルにしているのは、**2回目以降が圧倒的に速くなる**から。
WebPはすでに圧縮済みなのでgzipが効かず、base64にすると33%膨らむ。別ファイルなら並列に落ちてきて、ブラウザのキャッシュにも残る。

| | 埋め込み | 分割（今） |
|---|---|---|
| 初回 | 310KB（毎回） | 281KB（画像は並列） |
| 2回目以降 | 310KB | **143KB**（gzipで52KB） |

ファイル名には中身のハッシュが `?v=` で付くので、絵を更新したときだけ取り直される。

> `file://` で直接開いた場合、ブラウザの制限で服の色替えだけ効かない（キャンバスが読めないため）。それ以外は動く。サーバー経由なら問題なし。

## 見た目の決め事

- **色は地がほぼ無彩色、差し色は1つ**（`--peach`）。キャラの絵が主役なので、まわりが色を持つと画面が散らかる
- **絵文字はUIに使わない**。ボタンや連続日数のアイコンはインラインSVG（端末ごとに絵が変わらないし、色を文字色に揃えられる）
- **枠線とオフセットの黒ベタ影は使わない**。面の明るさと、ぼかした影（`--sh-1/2/3`）で階層を作る
- **端末がダークならUIも暗くなる**。部屋は真っ黒にせず「夜のなるねぇの部屋」として落とす
- 踊っている間は部屋の小物（窓・棚・クローゼット）を引っ込める

## 育成の仕組み

| 要素 | 内容 |
|---|---|
| **たまご → 進化** | 初回はたまご。タップで温めて孵化。お世話した日数で `ちび → なるねぇ → おとな → カリスマ` と大きくなる（2日 / 5日 / 10日） |
| **ぷに（体型）** | 食事で増え、運動・ダンス・片付けで減る。数値に応じて横に太ったり、細く背が伸びたりする |
| **きれい** | 部屋の片付け・ダンス・ヘルシー食で上がる。高いとキラキラのオーラ、低いとくすんでモワモワ線が出る |
| **部屋の散らかり** | うんちの代わり。時間経過（約2.5時間に1つ）とごほうび食で床にゴミが落ちる。タップで片付け。放置すると部屋がくすみ、キゲンときれいが下がる |
| **ダンス** | リズムゲーム（約20秒）。♪が◯に重なった瞬間にタップ。ランク S/A/B/C で ぷに・きれい・キゲンが変わる |
| **クローゼット** | 実績で服8種・アクセ7種が増える。服はスプライトのシャツ／短パンの画素だけ Canvas で色替え（絵を描き足さずに衣装が変わる） |

## なるねぇの絵

なるねぇは**コマ送りもしないし、パーツを切って重ねてもいない**。
1枚のフラットな2Dイラストに**格子（メッシュ）を張って、各頂点を骨に重みで縛り**、毎フレーム座標を計算し直して WebGL で描いている。
関節では皮が「伸びる」ので、**切れ目そのものが存在しない＝隙間が構造的に出ない**。Live2D / Spine と同じ原理。

> Live2D Cubism をそのまま使うことはできない。`.moc3` は非公開のバイナリ形式で Cubism Editor（GUI）でしか作れず、メッシュもデフォーマも手作業で張る前提でスクリプトから叩けないため。
> なのでメッシュ生成・ボーンウェイト・スキニング・描画を全部自前で実装してある。自動メッシュ生成と自動ウェイトは、Cubism や Spine が中でやっていることと同じ。

| | 3Dレンダーの連番 | 2Dパーツ（切り絵） | 2Dメッシュ（今） |
|---|---|---|---|
| 画像 | 805KB | 60KB | 91KB |
| 実効フレームレート | 待機5.9fps／ダンス11.2fps | 60fps | 60fps |
| 関節の隙間 | ― | 丸い受けで塞ぐ | **構造的に出ない** |
| ポーズを足す | 絵を描き起こす | 数値を12個 | 数値を12個 |

### 作り方（`mesh.py`）

- **パーツ分け**は色のかたまりを種にして、黒い輪郭線を近い方へ分け合う（分水嶺／`flatseg.py`）。未割当 0px
- **格子**は26px間隔。絵にかかるマスだけ残す。縁の精度はテクスチャのαが持つので、格子は少し多めでいい（体455頂点・766三角形）
- **重みは測地距離**で作る。直線距離だと、手が顔の近くにあるだけで頭が腕に引きずられる。絵の中だけを伝う距離なら、そうならない
- さらに**骨ごとに「伝ってよい範囲」を切ってある**。頭と腕は絵の上で隣り合っているので、これをやらないと腕を上げたとき首がちぎれる
- **頭・ポニーテール・顔のパーツは別の絵として重ねる**。1枚の布に頭まで入れると、腕を上げたときに必ず首が引きちぎれる（Live2Dが頭を別メッシュにしているのと同じ理由）
- **肩と股は2段の関節**にして、角度を 0.45 / 0.55 に割ってある。1つの関節で90度曲げると、線形ブレンドは必ずトゲが出る（candy-wrapper）。2箇所に分散させると消える
- **ポニーテールもメッシュ**。付け根を頭に固定して、先へ行くほど振れるようにしてある。根元が動かなければ、フードの下の切り口は絶対に出てこない（＝耳の脇のチラつきが出ない）
- 顔から目・眉・口・ほっぺを抜いた跡は**平らな肌色で埋める**。フラット塗りなので跡が完全に消える

### 動かし方

関節は11個の数値だけ：`腕L,R / 脚L,R / 胴のひねり・沈み / 首の傾き・沈み / 体の位置x,y / つぶれ具合`。

- **ポーズ＝目標の角度**（`POSE`）。`setPose("cheer")` は角度の目標を差し替えるだけ
- 目標を追うのは**ばね**（`Spring`）。遅れて・行きすぎて・戻る、が「生きて見える」正体
- **ループも式で書く**（`CYCF`）。待機・ダンス・走る・ジャンプは時間の関数。コマではないので速さを変えても破綻しない
- 首は胴より柔らかいばね、**ポニーテールは首の“速さ”に引っぱられる**。この二段遅れが効く
- 腕は**＋で外へ上がる**。頭が大きいので100度を超えると手が顔の裏に隠れる
- ポーズ切替・なでる・ジャンプ・ダンスの拍で、ばねに**勢いを注入**する（`kickRig`）
- アクセは頭と同じ行列をCSSに渡して動かす（DOMのまま頭にくっつく）
- 服の色替えはテクスチャを Canvas で HSL 変換して貼り直す
- **WebGLが使えない端末**では、全身1枚の静止画に落ちる（ふわふわだけCSSが持っている）
- `prefers-reduced-motion` が有効な端末ではループを回さない

### 表情

なるねぇは目を開けない（閉じ笑い目がキャラクターの顔）。だからまばたきができない。
まばたきの役割は「不規則に起きる小さな顔の変化」なので、そこだけ別の形で残してある。

表情も**絵ではなく数値**。眉・目・口・ほっぺが独立した板なので、`[ずらす / 回す / 縦横に潰す]` の5値で作る（`EXPR`）。差分画像は1枚もいらない。

- **目の弧の強弱**：`いつもの → ゆるむ → ギュッと細める → 戻る` を2〜6秒おきに不規則に入れる
- **口パク**：吹き出しが文字を打っている間、口の縦倍率を 4.6Hz の正弦で動かす。タイマーで絵を差し替えないので途切れない
- **状態の表情**：キゲンかたいりょくが低いと `しょんぼり`、なでると `どや`、驚かせると `おどろき`

## 開発メモ

- デバッグ用 API：`window.__naru`（`set({...})` / `pose(name)` / `mess(n)` / `evolve()` / `dance()` / `unlockAll()` など）
- メッシュ・骨・重みは `MESH`（index.html に直接埋めてある。整数の並びに詰めて34KB）。座標は全部**元の絵（1254px）のまま**なので、ポーズの数値もその座標系で読める
- 描画枠は表示枠より広く取ってある（136%×108%）。腰を画面の中心に置くと、ポニーテールが右にはみ出して切れるため
- 部屋の中での大きさは `FIT`（0.78）。クローゼット・棚・たまごとのバランスで決めた値。ここを1.0にすると頭が棚に届いて窮屈になる
- `mesh.py` を回すと `flat/mesh.json` と `flat/mesh_tex.png` が出る。`build.py` がそれを index.html に埋めて `naru.webp` を書き出す
- 3Dレンダーの連番だった頃の状態はコミット `e0d9401` に残してある（`git checkout e0d9401 -- .` で一発で戻せる）
- 旧バージョン（v1）のセーブは自動で引き継ぐ（体重・連続日数・スタンプを保持し、遊んだ日数ぶん育った状態で始まる）
