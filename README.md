# なるねぇといっしょ｜笑けるダイエット育成

なるねぇを「たまごっち」みたいに育てる、1ファイル完結（`index.html`）のスマホ向け育成アプリ。
ビルド不要。`index.html` を開けば動く。データは端末の localStorage に保存。

## 育成の仕組み

| 要素 | 内容 |
|---|---|
| **たまご → 進化** | 初回はたまご。タップで温めて孵化。お世話した日数で `ちび → なるねぇ → おとな → カリスマ` と大きくなる（2日 / 5日 / 10日） |
| **ぷに（体型）** | 食事で増え、運動・ダンス・片付けで減る。数値に応じて横に太ったり、細く背が伸びたりする |
| **きれい** | 部屋の片付け・ダンス・ヘルシー食で上がる。高いとキラキラのオーラ、低いとくすんでモワモワ線が出る |
| **部屋の散らかり** | うんちの代わり。時間経過（約2.5時間に1つ）とごほうび食で床にゴミが落ちる。タップで片付け。放置すると部屋がくすみ、キゲンときれいが下がる |
| **ダンス** | リズムゲーム（約20秒）。♪が◯に重なった瞬間にタップ。ランク S/A/B/C で ぷに・きれい・キゲンが変わる |
| **クローゼット** | 実績で服8種・アクセ7種が増える。服はスプライトのシャツ／短パンの画素だけ Canvas で色替え（絵を描き足さずに衣装が変わる） |

## 実績で手に入るもの

- 服：ミントジャージ（運動5回）／ピンクワンピ（きれい80）／ネイビースポ（ダンスA）／ラベンダー（7日連続）／くろスポ（片付け20回）／あかスポ（スタンプ30）／ゴールド（カリスマ進化）
- アクセ：リボン（初めてのお世話）／おはな（片付け10回）／ハチマキ（運動10回）／サングラス（ダンス5回）／ヘッドホン（ダンス10回）／クラウン（ダンスS）

## なるねぇの絵

なるねぇの見た目は、**3Dレンダーを12ポーズぶん焼いたスプライトシート**（4列×9行 / 1コマ 324×355px / WebP・透過つき 169KB）。
`background-position` を差し替えるだけでポーズが変わるので、画像は1リクエストで済み、どの端末でも同じ絵が出る。
リアルタイムの3Dは積んでいない（描画が重くWebGL依存になるわりに、焼いた絵に画で勝てなかったため）。

- ポーズ：`jump / cheer / dance / clap / kiss / thanks / yay / hmm / run / sorry / win / sleep`
- 服の色替えは、シャツ（黄）と短パン（グレー）の画素だけを Canvas で HSL 変換する。元の陰影はそのまま残るので、塗り替えても立体感が消えない

### パーツを分けて揺らす

絵を差し替えるだけだと「紙が切り替わった」ようにしか見えない。動いて見えるものは、**体のパーツが別々に、少しずつ遅れて**動いている。
そこで1コマを **体 / 頭 / ポニーテール** の3層に切り分けてシートに持たせ、層ごとに別の動きをつけている（だから9行ある）。

- 切り分けは色で自動判定（こげ茶＝ポニーテール、クリーム＋肌色のかたまり＝頭、残り＝体）。頭は円で切るので、ポーズが変わっても切り口が安定する
- 層をずらすと下から穴が見えるので、**隠れる部分をまわりの色でにじませて埋めてある**（`fill_from`）。体の層は頭に完全に隠れる内側を透明にして容量を削っている
- 動きは位置ではなく**ばね**（`Spring`）で解く。頭は体を追い、ポニーテールは頭の“速さ”に引っぱられてさらに遅れる。遅れて・行きすぎて・戻る、が生きて見える正体
- ポーズ切替・なでる・ジャンプ・ダンスの拍で、ばねに**勢いを注入**する（`kickRig`）。キゲンやたいりょくが低いと振れ幅が落ちる
- アクセは頭の層に入っているので、頭と一緒に揺れる
- `prefers-reduced-motion` が有効な端末ではループを回さない

## 開発メモ

- デバッグ用 API：`window.__naru`（`set({...})` / `pose(name)` / `mess(n)` / `evolve()` / `dance()` / `unlockAll()` など）
- スプライトシートは3Dレンダーの12ポーズを共通の切り抜き窓で書き出したもの。窓が同じなので、コマを差し替えても体の大きさと足の位置がズレない
- 層ごとの回転の中心は `RIG[]`（頭のx,y／ポニーテールの付け根x,y）に%で持っている
- 旧バージョン（v1）のセーブは自動で引き継ぐ（体重・連続日数・スタンプを保持し、遊んだ日数ぶん育った状態で始まる）
