# なるねぇといっしょ｜笑けるダイエット育成

なるねぇを「たまごっち」みたいに育てる、スマホ向けの育成アプリ。
データは端末の localStorage に保存。

## 置くもの

| ファイル | 中身 | 大きさ |
|---|---|---|
| `index.html` | HTML・CSS・ゲームのコード全部 | 105KB（gzipで34KB） |
| `naru.webp` | なるねぇのパーツアトラス（15パーツを1枚に） | 55KB |
| `jar.webp` | 棚のChenMeのボトル | 7KB |
| `icon.png` | ホーム画面用のアイコン | 40KB |

**4つとも同じ場所に置く**（サブディレクトリは不可）。静的ファイルを置けるところなら何でも動く。

画像を埋め込まずに別ファイルにしているのは、**2回目以降が圧倒的に速くなる**から。
WebPはすでに圧縮済みなのでgzipが効かず、base64にすると33%膨らむ。別ファイルなら並列に落ちてきて、ブラウザのキャッシュにも残る。

| | 埋め込み | 分割（今） |
|---|---|---|
| 初回 | 240KB（毎回） | 208KB（画像は並列） |
| 2回目以降 | 240KB | **105KB**（gzipで34KB） |

ファイル名には中身のハッシュが `?v=` で付くので、絵を更新したときだけ取り直される。

> `file://` で直接開いた場合、ブラウザの制限で服の色替えだけ効かない（キャンバスが読めないため）。それ以外は動く。サーバー経由なら問題なし。

## 見た目の決め事

- **色は地がほぼ無彩色、差し色は1つ**（`--peach`）。キャラの絵が主役なので、まわりが色を持つと画面が散らかる
- **絵文字はUIに使わない**。ボタンや連続日数のアイコンはインラインSVG（端末ごとに絵が変わらないし、色を文字色に揃えられる）
- **枠線とオフセットの黒ベタ影は使わない**。面の明るさと、ぼかした影（`--sh-1/2/3`）で階層を作る
- **端末がダークならUIも暗くなる**。部屋は真っ黒にせず「夜のなるねぇの部屋」として落とす
- 踊っている間は部屋の小物（窓・棚・クローゼット）を引っ込める

## 育成の仕組み

| 要素 | 内容 |
|---|---|
| **たまご → 進化** | 初回はたまご。タップで温めて孵化。お世話した日数で `ちび → なるねぇ → おとな → カリスマ` と大きくなる（2日 / 5日 / 10日） |
| **ぷに（体型）** | 食事で増え、運動・ダンス・片付けで減る。数値に応じて横に太ったり、細く背が伸びたりする |
| **きれい** | 部屋の片付け・ダンス・ヘルシー食で上がる。高いとキラキラのオーラ、低いとくすんでモワモワ線が出る |
| **部屋の散らかり** | うんちの代わり。時間経過（約2.5時間に1つ）とごほうび食で床にゴミが落ちる。タップで片付け。放置すると部屋がくすみ、キゲンときれいが下がる |
| **ダンス** | リズムゲーム（約20秒）。♪が◯に重なった瞬間にタップ。ランク S/A/B/C で ぷに・きれい・キゲンが変わる |
| **クローゼット** | 実績で服8種・アクセ7種が増える。服はスプライトのシャツ／短パンの画素だけ Canvas で色替え（絵を描き足さずに衣装が変わる） |

## 実績で手に入るもの

- 服：ミントジャージ（運動5回）／ピンクワンピ（きれい80）／ネイビースポ（ダンスA）／ラベンダー（7日連続）／くろスポ（片付け20回）／あかスポ（スタンプ30）／ゴールド（カリスマ進化）
- アクセ：リボン（初めてのお世話）／おはな（片付け10回）／ハチマキ（運動10回）／サングラス（ダンス5回）／ヘッドホン（ダンス10回）／クラウン（ダンスS）

## なるねぇの絵

なるねぇは**コマ送りしていない**。1枚のフラットな2Dイラストを**15個のパーツに切り分けたアトラス**（1024×439 / WebP・透過つき 55KB）を持ち、
パーツを関節でつないで、**角度を毎フレーム計算して動かしている**（切り絵アニメ／ボーンリグ）。
だから「コマ数」という概念がなく、どの速度でも 60fps で連続に動く。ポーズを増やしても絵は増えない。

| | 前（3Dレンダーの連番） | 今（2Dリグ） |
|---|---|---|
| 画像 | 805KB（48ポーズ＋表情シート） | **55KB** |
| 実効フレームレート | 待機5.9fps／ダンス11.2fps（間は不透明度で溶かして補間） | **60fps（補間ではなく本物）** |
| ポーズを足す | 絵を描き起こす | 数値を12個書く |

- パーツは `ポニテ / フード / 顔 / 眉L,R / 目L,R / 口 / ほっぺL,R / 胴 / 腕L,R / 脚L,R` の15個
- 切り分けは色で自動判定したかたまりを種にして、**黒い輪郭線を近いパーツへ分け合う**（分水嶺／`flatseg.py`）。未割当 0px で切れる
- 切り口に白い線が出るので、各パーツを**2px太らせて隣と重ねてある**（`export2d.py`）。後ろのパーツが必ず下敷きになるので継ぎ目が消える
- 顔から目・眉・口・ほっぺを抜いた跡は**平らな肌色で埋める**。フラット塗りなので、跡が完全に消える（3Dレンダーではこれができなかった）
- 服の色替えは、シャツ（黄）と短パン（グレー）の画素だけを Canvas で HSL 変換する

### 動かし方

関節は11個の数値だけ：`腕L,R / 脚L,R / 胴のひねり・沈み / 首の傾き・沈み / 体の位置x,y / つぶれ具合`。

- **ポーズ＝目標の角度**（`POSE`）。`setPose("cheer")` は角度の目標を差し替えるだけで、絵は切り替わらない
- 目標を追うのは**ばね**（`Spring`）。遅れて・行きすぎて・戻る、が「生きて見える」正体なので、位置ではなくばねで解く
- **ループも式で書く**（`CYCF`）。待機・ダンス・走る・ジャンプは時間の関数。コマではないので、速さを変えても破綻しない
- 首は胴より柔らかいばね、**ポニーテールは首の“速さ”に引っぱられる**（動いた方向と逆に流れる）。この二段遅れが効く
- 腕は**＋で外へ上がる**。頭が大きいキャラなので、100度を超えると手が顔の裏に隠れる。ポーズの上限はそこに合わせてある
- ポーズ切替・なでる・ジャンプ・ダンスの拍で、ばねに**勢いを注入**する（`kickRig`）。キゲンやたいりょくが低いと振れ幅が落ちる
- アクセは頭の層に入っているので、頭と一緒に揺れる
- `prefers-reduced-motion` が有効な端末ではループを回さない

### 表情

なるねぇは目を開けない（閉じ笑い目がキャラクターの顔）。だからまばたきができない。
まばたきの役割は「不規則に起きる小さな顔の変化」なので、そこだけ別の形で残してある。

表情も**絵ではなく数値**。眉・目・口・ほっぺが独立したパーツなので、`[ずらす / 回す / 縦横に潰す]` の5値で作る（`EXPR`）。差分画像は1枚もいらない。

- **目の弧の強弱**：`いつもの → ゆるむ → ギュッと細める → 戻る` を2〜6秒おきに不規則に入れる。閉じ目のままでも「顔が動いた」と認識される
- **口パク**：吹き出しが文字を打っている間、口の縦倍率を 4.6Hz の正弦で動かす。タイマーで絵を差し替えないので、途切れない
- **状態の表情**：キゲンかたいりょくが低いと `しょんぼり`、なでると `どや`、驚かせると `おどろき`
- 表情の切り替えも 24/秒 で目標へ寄せるので、パッと変わらず、すっと変わる

## 開発メモ

- デバッグ用 API：`window.__naru`（`set({...})` / `pose(name)` / `mess(n)` / `evolve()` / `dance()` / `unlockAll()` など）
- パーツの位置・大きさ・関節の座標は `ATLAS`（index.html に直接埋めてある。小さいので取りに行かせない）。リグの中身は常に 432×549 で考えて、表示サイズぶんだけ拡大する
- 枠の中心ではなく**腰を画面の中心に合わせている**（ポニーテールのぶん枠が右に伸びているため）
- 3Dレンダーの連番だった頃の状態は git タグ `v1-3dsprite` に残してある
- 旧バージョン（v1）のセーブは自動で引き継ぐ（体重・連続日数・スタンプを保持し、遊んだ日数ぶん育った状態で始まる）
